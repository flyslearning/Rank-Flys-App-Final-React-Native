# Rank Flys

**Rank Flys** is an EdTech platform designed to help students prepare for competitive examinations such as **NEET** and **JEE**.

The platform is focused on providing students with an organized learning experience and educational resources to support their exam preparation.

Rank Flys is available as an Android application on the **Google Play Store**.

## About Rank Flys

Rank Flys aims to make competitive exam preparation more accessible, organized, and student-friendly.

The project is being developed with a focus on:

* Competitive exam preparation
* Student learning experience
* Educational resources
* Practice and assessment
* Continuous improvement based on student feedback

## Exams Supported

Rank Flys is designed to support students preparing for:

* **NEET**
* **JEE**

The available content and features may evolve as the platform develops.

## Getting Started

### Prerequisites

Before setting up the project locally, make sure you have the required development tools installed.

Typical requirements include:

* Node.js
* npm or Yarn
* Git
* Android Studio
* Android SDK
* Java / JDK compatible with the project
* Expo CLI or the project's required development tooling

### Clone the Repository

```bash
git clone https://github.com/flyslearning/Rank-Flys-App-Final-React-Native.git
```

Enter the project directory:

```bash
cd Rank-Flys-App-Final-React-Native
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

If the project uses Expo:

```bash
npx expo start
```

For Android development, use the appropriate Android development environment or Expo workflow configured for the project.

> Follow the project's existing configuration files and development documentation if additional setup is required.

## Reporting Issues

If you find a bug or have a feature suggestion, please use **GitHub Issues**.

When reporting a bug, please provide:

1. A clear description of the issue.
2. Steps to reproduce it.
3. Expected behavior.
4. Actual behavior.
5. Relevant device or Android version information.
6. Screenshots or logs when appropriate.

Please do not include passwords, API keys, authentication tokens, personal information, or other sensitive data in public issues.
