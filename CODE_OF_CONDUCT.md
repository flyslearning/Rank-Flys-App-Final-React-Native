# Code of Conduct

## Our Commitment

We are committed to making the Rank Flys community a welcoming, respectful, inclusive, and constructive environment for everyone.

Rank Flys is an open-source EdTech project focused on helping students prepare for competitive examinations such as **NEET** and **JEE**. Contributors may have different backgrounds, experiences, opinions, and levels of technical expertise.

We expect all community members to communicate respectfully and professionally.

## Expected Behavior

All contributors and community members are expected to:

* Treat others with respect and professionalism.
* Be welcoming to new contributors.
* Communicate clearly and constructively.
* Give and receive constructive feedback.
* Respect different viewpoints and experiences.
* Focus discussions on improving the project.
* Help create a positive environment for students, educators, developers, and contributors.
* Respect the privacy of other community members.
* Follow applicable project rules and GitHub policies.
* Report security issues responsibly through the process described in `SECURITY.md`.

## Unacceptable Behavior

The following behavior is not acceptable in Rank Flys project spaces:

* Harassment, discrimination, or intimidation.
* Personal attacks or targeted insults.
* Threats or threatening behavior.
* Hate speech or abusive language.
* Deliberate disruption of discussions or project activities.
* Trolling or repeated bad-faith behavior.
* Publishing someone's private or personal information without permission.
* Sharing passwords, API keys, authentication tokens, or other confidential information.
* Sexual harassment or unwanted sexual content.
* Deliberately submitting malicious code or content.
* Submitting copyrighted or proprietary material without the necessary rights.
* Any other behavior that is inappropriate, unsafe, or harmful to the community.

## Educational Content

Rank Flys is an educational platform serving students preparing for competitive examinations.

When contributing educational content, contributors should:

* Aim for accuracy and clarity.
* Avoid intentionally misleading information.
* Respect copyright and intellectual property rights.
* Provide sources where appropriate.
* Avoid submitting confidential or unauthorized examination material.
* Avoid sharing private information about students, teachers, or other individuals.
* Communicate disagreements about educational content respectfully.

## Respectful Discussions

Technical and educational discussions may involve disagreement.

Disagreement itself is welcome when it is expressed constructively.

When discussing code, features, educational content, or project decisions:

* Focus on the issue rather than the individual.
* Explain the reasoning behind your suggestion.
* Provide useful evidence or examples when possible.
* Avoid hostile or dismissive language.
* Be open to feedback and alternative approaches.

## Reporting Unacceptable Behavior

If you experience or observe behavior that violates this Code of Conduct, please report it privately to the Rank Flys project maintainers.

When reporting an incident, provide:

* A description of what happened.
* The relevant GitHub issue, pull request, discussion, or other location.
* The date or approximate time of the incident.
* Any relevant screenshots or other evidence, when appropriate.

Please avoid publicly reposting private information or sensitive details about the incident.

## Security Reports

Security vulnerabilities should not be reported through public GitHub Issues, Discussions, or Pull Requests.

If you discover a security vulnerability, please follow the reporting process described in [SECURITY.md](SECURITY.md).

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct in official Rank Flys project spaces.

Depending on the circumstances and severity of a violation, maintainers may take appropriate action, including:

* Removing inappropriate content.
* Requesting changes to a contribution.
* Closing an issue, discussion, or pull request.
* Temporarily restricting participation.
* Permanently restricting participation.
* Taking other reasonable actions necessary to protect the community.

Enforcement decisions will be made with the goal of maintaining a respectful, constructive, and safe project environment.

## Scope

This Code of Conduct applies to official Rank Flys project spaces, including:

* GitHub Issues
* Pull Requests
* GitHub Discussions, if enabled
* Project documentation
* Code reviews
* Other official project communication spaces

It also applies when an individual is representing the Rank Flys project or community in other public spaces.

## Good-Faith Participation

We encourage contributors to participate in good faith.

If you make a mistake, correct it.

If someone points out a problem with your contribution, consider the feedback constructively.

The goal of the project is collaboration and continuous improvement.

## Maintainer Responsibilities

Project maintainers will make reasonable efforts to:

* Keep project discussions constructive.
* Address reported violations appropriately.
* Protect community members from harassment and abuse.
* Protect sensitive information.
* Apply project rules consistently.
* Encourage respectful collaboration.

## No Retaliation

Retaliation against someone who reports a violation of this Code of Conduct in good faith is not acceptable.

Reports should be handled respectfully and as confidentially as reasonably possible.

## Changes to This Code of Conduct

This Code of Conduct may be updated as the Rank Flys community and project evolve.

Significant changes will be communicated through the project's official GitHub repository.

## Contact

For general project questions, please use the appropriate GitHub Issues or Discussions.

For security vulnerabilities, follow the instructions in [SECURITY.md](SECURITY.md).

For Code of Conduct concerns, contact the Rank Flys project maintainers through the project's designated private communication channel.

## Acknowledgement

By participating in the Rank Flys community, you agree to follow this Code of Conduct and help maintain a respectful and constructive environment.

Thank you for helping make **Rank Flys** a welcoming open-source project for developers, educators, students, and contributors.
